# 🤖 ربات هوش مصنوعی تلگرام (چت 💬 | عکس 🎨 | ویدیو 🎬)

ربات تلگرامی با دکمه‌های رنگی 🔵🟢🔴 و پنل مدیریت مخفی (فقط برای مدیر).
هر سرویس هوش مصنوعی که API سازگار با OpenAI داره (UnoRouter، BytePlus، OpenAI، OpenRouter، Gemini، DeepSeek، Groq، ...) از داخل خود ربات وصل میشه؛ لازم نیست به کد دست بزنی.

## ✨ امکانات
- 💬 **چت** با حافظه گفتگو + تحلیل عکس (مدل‌های Vision)
- 🎨 **ساخت عکس** (BytePlus Seedream، OpenAI و ...) با دکمه «🔁 دوباره بساز»
- 🎬 **ساخت ویدیو** (BytePlus Seedance، Sora-style) با نمایش وضعیت زنده
- 🔄 هر کاربر مدل دلخواهش رو تو هر بخش انتخاب می‌کنه
- 🛠 **پنل مدیریت** (فقط آیدی‌های داخل `ADMIN_IDS` می‌بینن):
  - 🔌 افزودن سرویس و API Key (پیام کلید خودکار پاک میشه 🔒)
  - 🧪 تست اتصال، 📥 دریافت خودکار لیست مدل‌ها با جستجو
  - 🤖 افزودن/حذف/فعال/غیرفعال/پیش‌فرض کردن مدل‌ها برای هر بخش
  - 👥 تایید دستی کاربران جدید (✅ / ❌)، مسدود کردن، جستجو
  - 📏 سهمیه روزانه برای هر بخش، 🚧 حالت تعمیر، 🧠 پرامپت سیستم
  - 📢 پیام همگانی، 📊 آمار

## 🚀 راه‌اندازی (قدم به قدم)

### ۱) ساخت ربات
1. تو تلگرام برو سراغ **@BotFather** ← `/newbot` ← توکن رو کپی کن.
2. آیدی عددی خودت رو از **@userinfobot** بگیر.

### ۲) آپلود روی GitHub
1. تو github.com یه Repository جدید بساز (Private بهتره).
2. **Add file ← Upload files** و همه فایل‌ها رو آپلود کن (همه کنار هم، بدون پوشه):
   `main.py` `handlers.py` `ai.py` `db.py` `tg.py` `config.py` `requirements.txt` `Dockerfile` `railway.json` `README.md`
3. **Commit changes**.

### ۳) اجرا روی Railway
1. railway.com ← **New Project ← Deploy from GitHub repo** ← ریپو رو انتخاب کن.
2. تب **Variables** این‌ها رو اضافه کن:

| متغیر | مقدار |
|---|---|
| `BOT_TOKEN` | توکن BotFather |
| `ADMIN_IDS` | آیدی عددی خودت (چندتا با کاما: `111,222`) |
| `DB_PATH` | `/data/bot.db` |

3. ⚠️ **خیلی مهم:** روی سرویس راست‌کلیک ← **Attach Volume** ← Mount path: `/data`
   (بدون Volume با هر Redeploy کلیدها و تنظیمات پاک میشن.)
4. Deploy. تو Logs باید ببینی: `Bot @YourBot started`.
5. ⚠️ فقط **۱ نسخه** (Replica) اجرا کن، وگرنه تلگرام خطای Conflict میده.

### ۴) تنظیم از داخل ربات
1. `/start` ← **🛠 پنل مدیریت** ← **🔌 سرویس‌ها** ← **➕ افزودن**
2. **UnoRouter** رو بزن، کلید رو بفرست ← ۸ مدل رایگان خودکار به چت اضافه میشه 🎁
3. **BytePlus ModelArk** رو بزن، کلید رو بفرست ← **📥 دریافت لیست مدل‌ها** یا از **🤖 مدل‌ها ← ➕** دستی اضافه کن:
   - 🎨 عکس: Model ID مدل Seedream (مثلا `seedream-4-0-250828`)
   - 🎬 ویدیو: Model ID مدل Seedance (مثلا `seedance-1-0-pro-250528`)
   - 💬 چت: DeepSeek / Dola-Seed / GLM
   - Model ID دقیق رو از کنسول BytePlus (صفحه هر مدل) کپی کن و حتما تو **Model activation** فعالش کن.
4. با **🧪 تست مدل** مطمئن شو جواب میده ✅

## 🧩 نکات
- دکمه‌های رنگی رو نسخه‌های جدید تلگرام (بعد از فوریه ۲۰۲۶) نشون میدن؛ نسخه‌های قدیمی دکمه معمولی می‌بینن.
- منطقه BytePlus پیش‌فرض `ap-southeast` هست؛ اگه منطقه دیگه‌ای داری از «🌐 تغییر آدرس» عوضش کن.
- پارامترهای ویدیو (مدت، کیفیت، نسبت) از ⚙️ تنظیمات ← 🎞 قابل تغییره.
- نسخه پایتون (3.12) و کتابخونه‌ها تو Dockerfile قفل شدن، پس روی Railway همیشه یکسان بیلد میشه.
